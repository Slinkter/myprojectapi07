Una aplicación React moderna para explorar Pokémon.

## 🛠️ Tech Stack

- React 18 + Vite 5
- Redux Toolkit (Estado)
- Tailwind CSS (Estilos)
- Motion (Animaciones)
- Storybook (Componentes)
- PokéAPI (Datos)

## 🚀 Scripts

```bash
pnpm dev          # Desarrollo
pnpm build        # Build producción
pnpm deploy       # Desplegar a GitHub Pages
pnpm storybook   # Documentación de componentes
```
