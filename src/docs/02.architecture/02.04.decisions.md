# Registro de Decisiones Arquitectónicas (ADRs)

---

## ADR-001: Tailwind CSS sobre MUI/Chakra

**Contexto**: Frameworks de componentes consumen bundle y limitan personalización.
**Decisión**: Tailwind CSS 3.4 utility-first.
**Razón**: Zero runtime cost, diseño pixel-perfect, dark mode nativo, responsive fácil.

---

## ADR-002: Feature-Sliced Design

**Contexto**: Estructuras por tipo (`components/`, `hooks/`, `utils/`) se vuelven inmanejables.
**Decisión**: Agrupar por dominio funcional (features).
**Razón**: Alta cohesión, bajo acoplamiento, equipos pueden trabajar en paralelo sin conflictos.

---

## ADR-003: Redux Toolkit Thunks sobre Redux-Saga

**Contexto**: Sagas añaden boilerplate y curva de aprendizaje.
**Decisión**: `createAsyncThunk` de RTK.
**Razón**: Simplicidad, integración nativa con slices, menos boilerplate.

---

## ADR-004: Axios como HTTP Client

**Contexto**: Fetch API nativa requiere boilerplate para interceptores y error handling.
**Decisión**: Axios con instancia configurada en `src/lib/httpClient.js`.
**Razón**: Interceptors globales, timeout, error handling centralizado.

---

## ADR-005: Hash Router para GitHub Pages

**Contexto**: BrowserRouter causa 404 en refresh en hosting estático.
**Decisión**: `createHashRouter` de react-router-dom.
**Razón**: El hash `#/` es manejado 100% por el cliente, el servidor siempre sirve `index.html`.

---

## ADR-006: Cache Híbrido (Memory + localStorage + Seed)

**Contexto**: PokéAPI tiene rate limits y latencia de red.
**Decisión**: 3 niveles de cache con fallback.
**Razón**: Velocidad (memory) + persistencia (localStorage) + offline (seed data).

---

## ADR-007: JSDoc sobre TypeScript

**Contexto**: Migrar a TypeScript requiere refactor completo.
**Decisión**: JSDoc type annotations en JavaScript.
**Razón**: IntelliSense en VS Code sin compilar, migración incremental posible.

---

## ADR-008: Motion sobre CSS Animations

**Contexto**: Animaciones CSS son limitadas para interacciones complejas.
**Decisión**: Motion (Framer Motion) para animaciones declarativas.
**Razón**: Spring physics, AnimatePresence, gestos (hover, tap), staggered delays.
