# Gestión de Importaciones y Alias `@`

> **Configuración**: `vite.config.js` + `jsconfig.json`

---

## Alias `@/`

El alias `@/` resuelve a `src/`. Evita imports relativos profundos (`../../../`).

```javascript
// vite.config.js
resolve: { alias: { "@": path.resolve(__dirname, "./src") } }

// jsconfig.json
{ "compilerOptions": { "paths": { "@/*": ["./src/*"] } } }
```

### Uso

```javascript
// ✅ Correcto
import { usePokemon } from "@/features/pokemon";
import { cn } from "@/lib/utils";

// ❌ Incorrecto
import { usePokemon } from "../../features/pokemon";
```

---

## Barriles (index.js)

Cada feature exporta su API pública desde `index.js`.

```javascript
// features/pokemon/index.js
export { default as pokemonReducer } from "./state/pokemonSlice";
export { usePokemon } from "./hooks/usePokemon";
export { usePokemonList } from "./hooks/usePokemonList";
export { usePokemonCard } from "./hooks/usePokemonCard";
export { PokemonCard } from "./components/PokemonCard";
export { PokemonList } from "./components/PokemonList";
export { PokemonDetail } from "./components/PokemonDetail";
export { PokemonSkeleton } from "./components/PokemonSkeleton";
export { PokedexHeader } from "./components/PokedexHeader";
export { PokemonContent } from "./components/PokemonContent";
export { default as pokemonApi } from "./api/pokemonApi";
export { selectProcessedPokemons } from "./state/pokemonSelectors";
```

**Consumo limpio**:

```javascript
import { usePokemon, PokemonCard, selectProcessedPokemons } from "@/features/pokemon";
```

## Reglas FSD de Importación

| Desde → Hasta | Permitido | Ejemplo |
|--------------|-----------|---------|
| app → pages, features, entities, shared | ✅ | `import router from "@/app/router"` |
| pages → features, entities, shared | ✅ | `import { usePokemon } from "@/features/pokemon"` |
| features → entities, shared, lib, services | ✅ | `import { mapToPokemonEntity } from "@/entities/pokemon"` |
| entities → shared, lib | ✅ | Solo utils puras, NUNCA Redux |
| shared → lib, utils | ✅ | Sin dependencias de features |
| features → pages | ❌ | Violación de capa |
| entities → features | ❌ | Violación de capa |
| shared → features | ❌ | Violación de capa |
