> **Stack**: React 18 + Redux Toolkit + Tailwind CSS + Motion

## 1. Facade (Fachada) — Custom Hooks

Los custom hooks act como fachada que abstrae la complejidad de Redux del componente.

```javascript
// usePokemon() oculta useDispatch, useSelector, y el thunk
export const usePokemon = () => {
  const dispatch = useDispatch();
  const { pokemons, isLoading, isError, error, totalCount } =
    useSelector((state) => state.pokemon);

  const fetchPokemons = useCallback(
    ({ page, limit = 20 }) => dispatch(fetchPokemons({ page, limit })),
    [dispatch]
  );

  return { pokemons, isLoading, isError, error, totalCount, fetchPokemons };
};
```

**Beneficio**: El componente solo importa el hook. No sabe de Redux.

## 2. Container / Presentation

| Capa | Responsabilidad | Ejemplo |
|------|----------------|---------|
| **Container** (Página) | Obtiene datos, maneja estado, despacha acciones | `PokedexPage.jsx` |
| **Presentation** (Componente) | Recibe props, renderiza UI | `PokemonCard.jsx`, `PokemonList.jsx` |

**Beneficio**: Componentes de presentación son reutilizables y testeables.

## 3. Memoized Selectors

`createSelector` de Redux Toolkit memoiza cálculos derivados. Solo recalcula si las dependencias cambian.

```javascript
export const selectProcessedPokemons = createSelector(
  [
    (state) => state.pokemon.pokemons,
    (state) => state.favorites.favoriteIds,
    (state) => state.search.searchFilter,
  ],
  (pokemons, favoriteIds, searchFilter) => {
    const favSet = new Set(favoriteIds);          // O(1) lookup
    return pokemons
      .map((p) => ({ ...p, favorite: favSet.has(p.id) }))
      .filter((p) => !searchFilter || p.name.includes(searchFilter));
  }
);
```

**Beneficio**: Evita re-renders y cálculos innecesarios.

## 4. Layout con Outlet

React Router permite layouts que envuelven rutas hijas.

```javascript
const MainLayout = () => (
  <div className="min-h-screen bg-slate-50 dark:bg-slate-900">
    <Navbar />
    <main><Outlet /></main>
  </div>
);
```

**Beneficio**: Estructura consistente sin duplicar código en cada página.

## 5. Singleton Service — HTTP Client

Una única instancia de Axios configurada con interceptores.

```javascript
const apiClient = axios.create({
  baseURL: "https://pokeapi.co/api/v2",
  timeout: 10000,
});

export default apiClient;
```

**Beneficio**: Un punto para interceptores, error handling, y configuración global.

---

## 6. React.memo

Todos los componentes de presentación están envueltos en `React.memo` para evitar re-renders cuando las props no cambian.

```javascript
export default React.memo(PokemonCard);
```

## 7. Suspense + Lazy Loading

Code splitting por ruta para reducir bundle inicial.

```javascript
const PokedexPage = lazy(() => import("@/pages/PokedexPage"));

// En router:
{ path: "/", element: <Suspense fallback={<PokemonSkeleton />}><PokedexPage /></Suspense> }
```
