## 🎯 CONTEXTO DEL PROYECTO (LEER PRIMERO)

### Qué es

Pokédex App — aplicación React para explorar Pokémon con búsqueda en tiempo real, favoritos con persistencia (localStorage), tema claro/oscuro, animaciones Motion y diseño responsive.

### Arquitectura FSD

```
src/
├── app/           # Router (hash), layouts globales
├── pages/         # Composición de páginas (PokedexPage, PokemonDetailPage)
├── features/      # Lógica de negocio encapsulada
│   ├── pokemon/   # API, componentes, hooks, state de Pokémon
│   ├── favorites/ # Sistema de favoritos
│   ├── search/    # Búsqueda y filtrado
│   └── theme/     # Toggle dark/light
├── entities/      # Modelos de dominio (pokemon types, mapper, seed, utils puras)
├── shared/        # Componentes reutilizables (Pagination, layouts, hooks)
├── store/         # Configuración Redux (4 slices)
├── lib/           # Utilidades (httpClient, logger, cn)
├── services/      # Configuración de API
└── utils/         # Constantes (UI, TYPE_COLORS)
```

## 02: ROL — QA ENGINEER & CODE ARCHITECT

### Propósito

Auditar y corregir código para garantizar robustez y mantenibilidad bajo estándares de 2026.

### Áreas de análisis

#### 1. DETECCIÓN DE BUGS

| Check           | Qué buscar                                                           |
| --------------- | -------------------------------------------------------------------- |
| Props inválidos | Props con prefijos CSS (`sm:size`) que React no entiende             |
| Env vars        | `process.env.NODE_ENV` → debe ser `import.meta.env.PROD` (Vite)      |
| Navegación      | `<a href>` interno → debe ser `<Link>` de react-router-dom           |
| Hardcoded paths | Rutas hardcodeadas → usar `import.meta.env.BASE_URL` o `useNavigate` |
| Race conditions | `useEffect` async sin cleanup/AbortController                        |
| Memory leaks    | Timers, subscriptions, listeners sin cleanup                         |

#### 2. CLEAN CODE

| Regla           | Detalle                                            |
| --------------- | -------------------------------------------------- |
| Naming          | Semántico (intención, no implementación)           |
| Scope           | `const`/`let` — nunca `var`                        |
| DRY             | Lógica duplicada → extraer a util/hook/constante   |
| JSDoc           | Funciones públicas con `@param`, `@returns`        |
| Sentinel values | NO usar `id: 0` para error → usar `null` o `throw` |

#### 3. REACT BEST PRACTICES

| Check        | Detalle                                               |
| ------------ | ----------------------------------------------------- |
| Memo         | `React.memo` en componentes puros repetitivos         |
| Dependencies | Arrays exactos en `useEffect`/`useMemo`/`useCallback` |
| Hooks        | Lógica compleja → custom hook separado                |
| Keys         | NO index de array como `key` en listas dinámicas      |

#### 4. ARQUITECTURA FSD

| Regla     | Detalle                                              |
| --------- | ---------------------------------------------------- |
| Direction | Features → Entities → Shared (nunca al revés)        |
| Entities  | Solo tipos, mappers, utils puras. NO Redux selectors |
| Features  | Lógica de negocio + state + componentes del dominio  |
| Shared    | Componentes reutilizables entre features             |

## 03: ROL — PERFORMANCE ENGINEER

### Propósito
Optimizar rendimiento de la app para dispositivos de gama baja y conexiones lentas.

### Análisis Big O

```

┌────────────────────────────────────────────────────────────────┐
│ COMPLEJIDAD TEMPORAL │
├──────────────┬──────────────┬─────────────────────────────────┤
│ O(1) │ Constante │ Map.get(), Set.has(), lookup │
│ O(log n) │ Logarítmica │ Binary search │
│ O(n) │ Lineal │ .map(), .filter(), .find() │
│ O(n log n) │ Linealítmica │ .sort() │
│ O(n²) │ Cuadrática │ Loop anidado → EVITAR │
│ O(2^n) │ Exponencial │ Recursión sin memo → EVITAR │
└──────────────┴──────────────┴─────────────────────────────────┘

```

### Transformaciones comunes en este proyecto

```

ANTES: O(n × m) — .find() en cada render
pokemons.find(p => p.id === pokemonId) // selector no memoizado

DESPUÉS: O(1) — Map lookup con selector memoizado
createSelector([selectAllPokemon], (pokemons) =>
new Map(pokemons.map(p => [p.id, p]))
)
map.get(pokemonId) // O(1)

```

```

ANTES: O(n × m) — .includes() en loop
pokemons.filter(p => favoriteIds.includes(p.id))

DESPUÉS: O(n) — Set lookup
const favSet = new Set(favoriteIds)
pokemons.filter(p => favSet.has(p.id))

```

### Checks de React Performance

| Check | Qué buscar | Fix |
|-------|-----------|-----|
| Selector no memoizado | Función nueva en cada llamada a `useSelector` | `createSelector` con factory |
| `useMemo` con array nuevo | Dependencia es array que cambia en cada render | Usar selector memoizado directo |
| Motion overload | >10 `motion.div` montando simultáneamente | CSS transitions para grid items |
| localStorage sync write | Serializar en cada write | Throttle/debounce a 2s |
| Cache sin límite | Map que crece indefinidamente | LRU eviction, max 50 entries |

### Diagrama de flujo de datos (cache)

```

         ┌─────────────────┐
         │   UI LAYER      │
         │  (Components)   │
         └────────┬────────┘
                  │ dispatch/select
         ┌────────┴────────┐
         │   STORE LAYER   │
         │  (Redux Slices) │
         └────────┬────────┘
                  │ fetch
         ┌────────┴────────┐
         │   CACHE LAYER   │
         │  Memory Map     │
         │  ↓ miss ↓       │
         │  localStorage   │
         │  ↓ miss ↓       │
         └────────┬────────┘
                  │ HTTP GET
         ┌────────┴────────┐
         │   API LAYER     │
         │   (PokéAPI)     │
         └─────────────────┘

````

### Lo que NO hacer

| ❌ Prohibido                          | ✅ Alternativa                        |
| ------------------------------------- | ------------------------------------- |
| `process.env.NODE_ENV`                | `import.meta.env.PROD`                |
| `<a href="/myprojectapi07/">` interno | `<Link to="/" />`                     |
| `sm:size={24}` en iconos              | Tamaño fijo o hook de media query     |

| Entity layer con Redux selectors      | Selectores van en feature layer       |
| `useEffect` sin dependency array      | Array explícito o remover el effect   |
| `console.group/table` sin level check | Usar `logger.group/table` con check   |
