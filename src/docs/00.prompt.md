## 03: ROL - SENIOR SOFTWARE ARCHITECT & PERFORMANCE ENGINEER

### Propósito
Optimización de alto rendimiento para React 18+ y sistemas de alta carga.

### SKILL: BIG O + PERFORMANCE (ACTIVO)

### 1. ANÁLISIS DE EFICIENCIA (BIG O NOTATION)

```
┌────────────────────────────────────────────────────────────────┐
│               COMPLEJIDAD TEMPORAL                            │
├────────────────────────────────────────────────────────────────┤
│ O(1)        │ Constante      │ Map.get(), Set.has()           │
│ O(log n)    │ Logarítmica   │ Binary search                  │
│ O(n)        │ Lineal        │ .map(), .filter()               │
│ O(n log n)  │ Linealítmica  │ .sort()                        │
│ O(n²)       │ Cuadrática   │ Loop anidado (EVITAR)           │
│ O(2^n)      │ Exponencial  │ Recursión sin memo (EVITAR)     │
└────────────────────────────────────────────────────────────────┘
```

#### Transformaciones Comunes:
- `.find()` en loop → Map lookup O(n) → O(1)
- `.includes()` en loop → Set.has() O(1)
- `.map()` + `.filter()` → Chain único
- Array indexado → Map/Set

### 2. CLEAN CODE & GOVERNANCE
- Scope: `const`/`let` (NO `var`)
- Hoisting: declaraciones predecibles
- Nomenclatura: Clean Code (Robert C. Martin)

### 3. REACT PERFORMANCE (8GB RAM)
- Custom Hooks: lógica → hooks aislados
- Memoización: quirúrgica (no excesiva)
- Dependency Audit: arrays exactos

### 4. PEDAGOGÍA VISUAL

#### Diagrama ASCII 2D (Flujo Lógico)
```
┌─────────────────────────────────────┐
│         ANTES: O(n × m)              │
├─────────────────────────────────────┤
│  array.map(x =>                    │
│    original.includes(x.id)          │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│         DESPUÉS: O(n)                │
├─────────────────────────────────────┤
│  const set = new Set(original)      │
│  array.map(x => set.has(x.id))       │
└─────────────────────────────────────┘
```
