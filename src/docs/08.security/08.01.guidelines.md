# Guías de Seguridad

> **Stack**: React 18 + Axios + localStorage

---

## 1. Cross-Site Scripting (XSS)

**Protección actual**: React escapa contenido JSX por defecto → previene XSS básicos.

**Precauciones**:
- NO usar `dangerouslySetInnerHTML` (no se usa en el proyecto)
- Los datos de PokéAPI son de confianza (API pública oficial)
- Si en el futuro se muestra contenido de usuario, sanitizar con `DOMPurify`

---

## 2. Dependencias

**Riesgo**: Paquetes comprometidos en la cadena de suministro.

**Prácticas**:
```bash
pnpm audit           # Identificar vulnerabilidades conocidas
pnpm outdated        # Ver dependencias desactualizadas
pnpm update          # Actualizar a versiones seguras
```

**Estado actual**: Solo dependencias de registros oficiales (npm).

---

## 3. Almacenamiento en Cliente

| Dato | Dónde | ¿Sensible? |
|------|-------|-----------|
| Favoritos (IDs) | localStorage (`favoriteIds`) | No |
| Tema | localStorage (`app_theme`) | No |
| Cache de Pokémon | localStorage (`pokemon_cache`) | No |

**No se almacena**: tokens, credenciales, datos personales.

---

## 4. Comunicaciones

- **PokéAPI**: HTTPS obligatorio (`https://pokeapi.co/api/v2`)
- **GitHub Pages**: HTTPS forzado por GitHub
- **No hay backend propio**: No hay datos sensibles en tránsito

---

## 5. Headers de Seguridad (servidor de despliegue)

GitHub Pages aplica headers básicos. Para otros hosting, configurar:

| Header | Valor | Propósito |
|--------|-------|-----------|
| `Content-Security-Policy` | `default-src 'self'` | Restringir fuentes de scripts |
| `X-Content-Type-Options` | `nosniff` | Prevenir MIME sniffing |
| `X-Frame-Options` | `DENY` | Prevenir clickjacking |
| `Strict-Transport-Security` | `max-age=31536000` | Forzar HTTPS |
