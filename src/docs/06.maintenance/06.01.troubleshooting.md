# Guía de Resolución de Problemas

> **Proyecto**: myprojectapi07

---

## 1. Dev Server no inicia

| Síntoma | Causa | Solución |
|---------|-------|----------|
| `pnpm dev` falla | Dependencias no instaladas | `pnpm install` |
| Puerto 5173 ocupado | Otro proceso en el puerto | `netstat -ano \| findstr :5173` → `taskkill /PID [PID] /F` |
| Error de sintaxis | Código roto | Revisar terminal, Vite indica archivo y línea |
| Node.js versión incorrecta | Versión incompatible | Usar Node.js 18+ LTS (`node -v`) |

## 2. UI no se renderiza correctamente

| Herramienta | Qué buscar |
|-------------|-----------|
| **Consola del navegador** (F12 → Console) | Errores de JavaScript, warnings de React |
| **Redux DevTools** (extensión) | Estado del store, acciones dispatcheadas, ¿el state cambia? |
| **React DevTools** (extensión) | Árbol de componentes, props, ¿se re-renderiza innecesariamente? |
| **Network tab** (F12) | ¿Las peticiones a PokéAPI responden 200? |

## 3. Datos incorrectos o faltantes

| Problema | Diagnóstico | Solución |
|----------|------------|----------|
| Lista vacía | Redux DevTools → ¿`pokemon.pokemons` tiene datos? | Verificar `fetchPokemons` se dispatch |
| Favoritos no persisten | F12 → Application → Local Storage → ¿existe `favoriteIds`? | Revisar `favoritesSlice` side effects |
| Búsqueda no filtra | Redux DevTools → ¿`search.searchFilter` cambia? | Verificar `setSearchFilter` action |
| Tema no cambia | localStorage → ¿existe `app_theme`? | Revisar `themeSlice` y `ThemeWrapper` |

## 4. Problemas de Performance

| Síntoma | Herramienta | Solución |
|---------|------------|----------|
| App lenta al cargar | Lighthouse (F12 → Lighthouse) | Verificar code splitting, bundle size |
| Re-renders excesivos | React DevTools Profiler | Identificar componentes sin `React.memo` |
| Animaciones con jank | Performance tab (F12) | Reducir motion.div en grid, usar CSS transitions |
| Memoria creciendo | Memory tab (F12) | Verificar memoryCache no crece sin límite |

## 5. Build falla

| Error | Causa | Solución |
|-------|-------|----------|
| `pnpm build` error | ESLint warnings como errores | `pnpm lint` → fix warnings |
| Módulo no encontrado | Import path incorrecto | Verificar alias `@/` y existencia del archivo |
| Out of memory | Seed data muy grande | Verificar `manualChunks` en vite.config.js |

## 6. Herramientas Esenciales

| Herramienta | Instalación | Uso |
|-------------|------------|-----|
| **Redux DevTools** | Extensión Chrome/Firefox | Inspeccionar store, acciones, time travel |
| **React DevTools** | Extensión Chrome/Firefox | Component tree, props, state, profiler |
| **ESLint** | `pnpm lint` | Errores estáticos |
| **Lighthouse** | F12 → Lighthouse | Performance, a11y, SEO, best practices |
