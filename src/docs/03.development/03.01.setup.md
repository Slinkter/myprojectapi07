# Setup del Entorno de Desarrollo

> **Requisitos**: Node.js 18+ | pnpm 8+ | Git

---

## 1. Instalar dependencias del sistema

### Node.js
Descargar desde [nodejs.org](https://nodejs.org/) (versión LTS recomendada).

Verificar:
```bash
node -v   # >= 18
npm -v
```

### pnpm
```bash
npm install -g pnpm
pnpm -v   # >= 8
```

### Git
```bash
git --version
```

---

## 2. Clonar y configurar

```bash
git clone https://github.com/Slinkter/myprojectapi07.git
cd myprojectapi07
pnpm install
```

---

## 3. Comandos disponibles

| Comando | Qué hace | URL |
|---------|----------|-----|
| `pnpm dev` | Servidor de desarrollo con HMR | http://localhost:5173 |
| `pnpm build` | Build de producción → `dist/` | — |
| `pnpm preview` | Previsualizar build de producción | http://localhost:4173 |
| `pnpm lint` | ESLint check | — |
| `pnpm storybook` | Storybook (componentes aislados) | http://localhost:6006 |
| `pnpm build-storybook` | Build de Storybook | — |
| `pnpm deploy` | Deploy a GitHub Pages | https://slinkter.github.io/myprojectapi07 |

---

## 4. Problemas comunes

| Problema | Solución |
|----------|----------|
| `pnpm install` falla | `pnpm store prune && pnpm install` |
| Puerto 5173 ocupado | `netstat -ano \| findstr :5173` → matar proceso |
| App no carga | Verificar consola del navegador y terminal |
| Node.js incorrecto | Usar `nvm` para gestionar versiones |
