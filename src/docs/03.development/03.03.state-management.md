> **Configuración**: `src/store/index.js` | 4 slices

## 1. Store

```javascript
configureStore({
  reducer: {
    pokemon: pokemonReducer,       // { pokemons, isLoading, isError, error, totalCount }
    search: searchReducer,        // { searchFilter: "" }
    favorites: favoritesReducer,  // { favoriteIds: [] }
    theme: themeReducer,         // { currentTheme: "light" | "dark" }
  },
  middleware: (getDefault) =>
    getDefault({ serializableCheck: false }).concat(reduxLogger),
})
```

**`serializableCheck: false`**: Los objetos de Pokémon tienen referencias anidadas que el checker marca falsamente como no-serializables.

  "pokemon/fetchPokemons",

### favoritesSlice (`features/favorites/state/favoritesSlice.js`)

```javascript
toggleFavorite(state, action) {
  const id = action.payload;
  const index = state.favoriteIds.indexOf(id);
  if (index > -1) state.favoriteIds.splice(index, 1);
  else state.favoriteIds.push(id);
  saveFavoritesToStorage(state.favoriteIds); // side effect
}
```

## 3. Selectores Memoizados

`selectProcessedPokemons` (`features/pokemon/state/pokemonSelectors.js`):

```javascript
createSelector(
  [
    (state) => state.pokemon.pokemons,
    (state) => state.favorites.favoriteIds,
    (state) => state.search.searchFilter,
  ],
  (pokemons, favoriteIds, searchFilter) => {
    const favSet = new Set(favoriteIds);
    return pokemons
      .map((p) => ({ ...p, favorite: favSet.has(p.id) }))
      .filter((p) => !searchFilter || p.name.includes(searchFilter));
  }
);
```

**Solo recalcula** si pokemons, favoriteIds, o searchFilter cambian.
