# Convenciones de Código

> **Stack**: React 18 + JSDoc + Tailwind CSS + PropTypes

---

## 1. Nomenclatura

| Elemento | Convención | Ejemplo |
|----------|-----------|---------|
| Componentes | `PascalCase` | `PokemonCard.jsx` |
| Hooks | `camelCase` + prefijo `use` | `usePokemon.js` |
| Archivos de util/servicio | `camelCase` | `httpClient.js` |
| Carpetas | `kebab-case` | `pokemon-list/` |
| Variables/funciones | `camelCase` | `fetchPokemons` |
| Constantes | `UPPER_SNAKE_CASE` | `API_CONFIG`, `UI_CONSTANTS` |
| Tipos JSDoc | `PascalCase` | `@typedef {Object} Pokemon` |

---

```jsx

 */

import PropTypes from "prop-types";

// 1. Imports externos
// 2. Imports internos (@/...)
// 3. Constantes locales (si las hay)

/**
 * @param {PokemonProps} props
 * @returns {JSX.Element}
 */
const PokemonCard = React.memo(({ id, name, types, sprite }) => {
  // 1. Hooks (useState, useEffect, custom hooks)
  // 2. Handlers (prefijo handle)
  // 3. Renderizado (JSX)
});

// 4. PropTypes
PokemonCard.propTypes = { ... };

// 5. Export
export default PokemonCard;
```

## 3. PropTypes

Todos los componentes que reciben props **deben** definir PropTypes:

```javascript
PokemonCard.propTypes = {
  id: PropTypes.number.isRequired,
  name: PropTypes.string.isRequired,
  types: PropTypes.arrayOf(PropTypes.string).isRequired,
  sprite: PropTypes.string.isRequired,
  favorite: PropTypes.bool.isRequired,
  onToggleFavorite: PropTypes.func.isRequired,
};
```

## 5. Tailwind CSS

- **Utility-first**: Preferir clases de Tailwind sobre CSS custom.
- **Clases condicionales**: Usar `cn()` de `@/lib/utils` (`clsx` + `tailwind-merge`).
- **Dark mode**: Siempre incluir variante `dark:` para cada clase de color/fondo.
- **Responsive**: Mobile-first (`sm:`, `md:`, `lg:` sobre base mobile).

```javascript
<div className="grid grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5 gap-4">
```

---

## 6. React

- **Componentes funcionales**: No class components.
- **React.memo**: En todos los componentes de presentación.
- **Hooks**: Dependencias exactas en arrays de `useEffect`, `useMemo`, `useCallback`.
- **Keys**: Nunca usar índice de array como `key` en listas dinámicas.
