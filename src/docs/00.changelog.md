## [1.0.0] — 2025-04-09

### Added

- **Motion Animations**: PokemonCard (entrance, hover, star spring), PokemonSkeleton (shimmer pulse), FavoritesBar (staggered), SearchBar (focus glow), PokedexHeader (letter spring), Pagination (hover/tap), PokemonDetailPage (page transitions), PokemonDetail (stat bars animate)
- **Storybook**: Stories para PokemonCard, PokemonSkeleton, PokedexHeader, Pagination, SearchBar
- **UI Plugins**: `clsx` + `tailwind-merge` (`cn()` utility), `react-hot-toast`, `react-lazy-load-image-component`
- **Mobile-First**: Responsive breakpoints, grid 2-col → 5-col, touch-friendly spacing

### Changed

- **Router**: `createBrowserRouter` → `createHashRouter` (GitHub Pages)
- **Layout**: Separated MainLayout (con Navbar) y DetailLayout (sin Navbar)
- **Vite**: `base` → `/myprojectapi07`

### Fixed

- Navbar oculto en página de detalle
- 404 en refresh (hash router)
- Tamaño de FavoritePokemon aumentado
