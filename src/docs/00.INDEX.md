**Principios Fundamentales**:

| Principio | Descripción | Aplicación |
|----------|-------------|------------|
| **Alta Cohesión** | Todo lo relacionado con una feature está en un solo lugar | `features/pokemon/` contiene todo: estado, UI, hooks |
| **Bajo Acoplamiento** | Features independientes se comunican via interfaces | `usePokemon()` como API pública |
| **Separación de Responsabilidades** | UI separada de lógica de negocio | Componentes limpios, lógica en hooks |

### 2.3 Slices y Thunks

```javascript
// Async Thunk para datos asíncronos
export const fetchPokemons = createAsyncThunk(
  "pokemon/fetchPokemons",
  async ({ page, limit }) => {
    const offset = (page - 1) * limit;
    return await pokemonApi.getPokemons(offset, limit);
  }
);

// Slice con extraReducers
const pokemonSlice = createSlice({
  name: "pokemon",
  initialState: { pokemons: [], isLoading: false, isError: false },
  extraReducers: (builder) => {
    builder
      .addCase(fetchPokemons.pending, (state) => {
        state.isLoading = true;
      })
      .addCase(fetchPokemons.fulfilled, (state, action) => {
        state.isLoading = false;
        state.pokemons = action.payload.results;
      })
      .addCase(fetchPokemons.rejected, (state) => {
        state.isError = true;
      });
  },
});
```

### 2.4 Selectores Memoizados

```javascript
// Optimización: solo se recalcula si cambian las dependencias
export const selectProcessedPokemons = createSelector(
  [selectPokemons, selectFavoriteIds, selectSearchFilter],
  (pokemons, favoriteIds, searchFilter) => {
    return pokemons.map(p => ({
      ...p,
      favorite: favoriteIds.includes(p.id)
    })).filter(p => 
      !searchFilter || p.name.includes(searchFilter)
    );
  }
);
```

### 3.3 Seed Data como Fallback

```javascript
// src/entities/pokemon/data/seed.js
export const POKEMON_SEED = [
  { id: 1, name: "bulbasaur", types: [...], sprites: {...} },
  // ... 150 Pokémon
];
```

**Justificación del "Por Qué"**:
1. **Offline parcial**: API no disponible → datos locales
2. **Velocidad**: Sin latencia para los más populares
3. **Testing**: Datos consistentes y predecibles

### Glosario de Términos

| Término | Definición |
|---------|------------|
| **FSD** | Feature-Sliced Design: Arquitectura basada en funcionalidades |
| **Slice** | Porción del estado Redux para una feature |
| **Thunk** | Acción asíncrona en Redux |
| **Selector** | Función para obtener estado derivado |
| **Memoización** | Cacheo de cálculos costosos |
| **Hook** | Función que usa estado de React |

- Visualización de lista paginada de Pokémon
- Búsqueda por nombre
- Gestión de favoritos con persistencia
- Alternar tema claro/oscuro
- Diseño responsivo

### Requerimientos No Funcionales

- LCP < 3s
- FID < 500ms
- Accesibilidad WCAG 2.1 AA
- Compatibilidad: Chrome, Firefox, Edge, Safari (últimas 2 versiones)
